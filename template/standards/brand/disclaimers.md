> **This file is a seeded stub, and it is deliberately unfinished.** It ships with the project so
> that the skills which route here point at something real from day one. Until the author approves
> a wording for a class, that class reads 'No entries yet.' and a document of that class carries
> no disclaimer, with an `AUTHOR TO CONFIRM` flag where it would go.

**Trading name** (as printed on every document): <%TRADING_NAME%>

**Jurisdiction**: <%JURISDICTION%>

The single home for every disclaimer the business's documents carry. `draft-section` copies the
wording for a document's class from here, unchanged; `standards/risk/BUSINESS.md` rule 4 governs
when one is required and how a waiver is recorded. One wording per class, so no two documents of
the same class ever say different things.

**How to add a wording.** Under the class heading: the wording in a blockquote, exactly as it is
to be printed; then **Where it goes** (for example 'directly under the title block'); then **In
LaTeX** (the same wording inside the preamble's `housenotice` environment). Date it, and record
the decision in `.claude/MEMORY.md` `## Decisions`. Each wording states what the document is not
(for example, not legal or financial advice), who must review it before it is relied on, and the
trading name exactly as above.
