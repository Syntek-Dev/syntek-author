# CONTEXT.md — standards/style/samples/

The author's own writing, kept as evidence of how they really sound. `learn-voice` reads these
to seed and test `standards/style/voice-notes.md`, and `draft-section` reads them beside the
voice notes before it drafts. Nothing here is AI-written, nothing here is part of the work, and
nothing here is ever edited: a sample tidied by a skill is no longer evidence of the author. The
template ships this folder empty; the author adds the samples.

## Directory Tree

```text
standards/style/samples/
├── CONTEXT.md                  ← this file
├── CLAUDE.md                   ← operating rules
└── NN-kebab-description.md     ← one piece of the author's own writing per file (added by the author)
```

## What's here

- `NN-kebab-description.md` — one sample, verbatim, with frontmatter: `source` (where it came
  from, in the author's words), `written` (DD/MM/YYYY; approximate is fine if it says so),
  `register` (which register in `voice-notes.md` it evidences) and `notes`. **Three or more
  samples** before `learn-voice` proposes a voice mark from them.
- A good sample is recent, unedited by anyone else, and in the register the work needs: a
  paragraph of the author's real prose teaches more than a page of description.
