# CONTEXT.md — standards/referencing/

The referencing standard: how the work cites its sources and prints its reference list. Harvard
(Cite Them Right) is generated by Pandoc `--citeproc` from a SQLite master through CSL-JSON;
nothing is ever hand-formatted, and citation keys never change once used. This folder states the
rules; the machinery that enforces them lives in `tooling/`, the citations live in the work, and
the sources themselves are recorded in `research/src/` before they are keyed.

## Directory Tree

```text
standards/referencing/
├── CONTEXT.md                  ← this file
├── CLAUDE.md                   ← operating rules
└── harvard-referencing.md      ← the standard: keys, citing in prose, source types, the pipeline
```

## What's here

- `harvard-referencing.md` — inline `[@key]` citations, page locators, stacked citations;
  lower-case `authorYYYY` keys with `a`/`b`/`c` disambiguation, **never renamed**; the source
  types and the columns each needs; statutes and sacred texts; scope by selection; the
  pipeline from database to proof; and where keys work. **Keys resolve only in Markdown
  documents**: a business LaTeX deliverable (`.tex`) writes its references out in full, and
  `promote-section` stops on a draft bound for one that still holds `[@` (rule 7).

```text
tooling/references.db (SQLite master: edit here, via add-reference)
  └─ tooling/export_refs.py → build/references.json (CSL-JSON) ─┐
the work's Markdown ──────────────────────────────────── Pandoc --citeproc + tooling/harvard.csl
                                                          ├─ .docx (editors, publishers)
                                                          └─ .pdf  (XeLaTeX proof)
```
