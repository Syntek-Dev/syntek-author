%   1. Copy it to the document's place in library/src/<family>/, named for the document
%      (kebab-case, with its version and date when it is versioned). Never fill it in here.
%   2. Replace every [BRACKETED] field. A field only the author can supply stays as
%      \fillme until they do; a decision only the author can make is a \dnote whose
%      text opens with AUTHOR TO CONFIRM and a colon. `make flags` lists every one, and
%      `make pdf ISSUE=1` refuses to issue the document while any is left.
%   3. Keep the parts in the order library/docs/reference/document-anatomy.md sets out:
%      this leading block → the preamble → the internal note → the title block → the
%      disclaimer for the document's class → the Document Control block, ending with its
%      version history → the body. Section 4 of the brand guide, in the brand folder
%      00-project.md ## Paths names (by default standards/brand/), says the same.
%   4. Render with: make pdf FILE=<this file>. XeLaTeX runs twice so every \ref resolves.
%
% The leading block comes first, always: `% unit:` names the unit brief in
% planning/src/units/ (it is how promote-section finds this document), and the two lines
% after it are the document's writing status (idea · outlined · draft · structural-review ·
% fact-check · line-edit · final), updated as it passes each gate in standards/verification/.
% Each section of the brief sits between a marker pair, `% section: <slug>` and
% `% end section: <slug>`, in plan order; promote-section replaces only what lies between a
% pair, and no marker is deleted, renamed or moved by hand. It then proves the words with
% make section-check FILE=<this file> SECTION=<slug> DRAFT=<the promoted draft>.
% Escape LaTeX specials in body text: \& \% \# \_ \$ \{ \}.
% No em dashes in client-facing copy; en dashes only in ranges.
