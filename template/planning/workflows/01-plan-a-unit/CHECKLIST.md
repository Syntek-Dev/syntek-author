# CHECKLIST.md — plan a unit, from idea to brief

**Last Updated**: <%DATE%> **Version**: 0.1.0 **Maintained By**: <%AUTHOR_NAME%>
**Language**: British English (en_GB)

> **See** `planning/docs/reference/unit-briefs.md` and the `grill-with-docs` skill. This procedure
> passes gate V1. Gates are cited from `standards/verification/verification.md` by number (V1, V2
> …) and never restated here.

## Pre-Conditions

- [ ] Read `.claude/CLAUDE.md` and `.claude/MEMORY.md`, then this folder's `CONTEXT.md` and `CLAUDE.md`. · _sonnet_
- [ ] Read the `grill-with-docs` skill and its mode file. · _sonnet_
- [ ] The unit, its position and its name confirmed with the author. · _opus_

## Execution Checklist

**Before questioning**

- [ ] Outline row present, or added on the author's word. · _sonnet_
- [ ] Checked for an existing brief; if one exists, the author confirmed a re-plan and every ledger-backed section slug is kept. · _sonnet_
- [ ] MEMORY, the neighbouring briefs, the research notes and any open map read; nothing asked that the repository answers. · _opus_

**The plan**

- [ ] Scope written: what is in, what is out, and where the out goes. · _opus_
- [ ] What this unit does written as a reader outcome. · _opus_
- [ ] `audience_note` set only where this unit's reader differs from the stated reader. · _opus_
- [ ] Settled-positions slot holds agreed positions only; undecided points flagged `AUTHOR TO CONFIRM`, unchecked claims flagged `VERIFY`. · _opus_
- [ ] Sections cut at roughly 300–500 words, one job each, in plan order, each with a slug and a one-line purpose. · _opus_
- [ ] `## Draws on` and `sources:` list only material the project holds; gaps written as research tasks. · _opus_

**Writing and recording**

- [ ] Brief written with `status: idea`, `verified: {}` and every section at `status: ""`. · _sonnet_
- [ ] Brief read back to the author and corrections applied. · _opus_
- [ ] On the author's agreement, V1 (idea → outlined) recorded: `status: outlined` and `V1` dated in `verified`. · _sonnet_
- [ ] Decisions that pass the memory gate recorded in `.claude/MEMORY.md`; new terms in `standards/style/terminology.md`. · _opus_
- [ ] For a re-plan, markers that no longer match the brief reported to the author; nothing in the content layer changed. · _sonnet_

## Done When

- [ ] **The author has agreed the brief, and a fresh session could draft its first section without asking what the unit is for.** · _opus_
- [ ] The outline and the brief agree on the unit's name and place. · _sonnet_
- [ ] The hand-back names the next procedure and offers to draft the first section. · _opus_
