# CONTEXT.md — planning/src/reviews/

Review reports: the written result of reading the work through one or more lenses — a
structural review of a unit, a panel over the whole work, a scheduled review of a document.
Every file here is **advice only**. A decision exists when the author makes and dates it in
`.claude/MEMORY.md`; until then, nothing a review says has changed anything.

## Directory Tree

```text
planning/src/reviews/
├── CONTEXT.md                        ← this file
├── CLAUDE.md                         ← operating rules
└── REVIEW-<scope>-DD-MM-YYYY.md      ← one report per review, named for the work it read
```

## What's here

- `REVIEW-<scope>-DD-MM-YYYY.md` — a report written by `structure-review`: header with the
  advice-only status line, lenses, verdicts by location, open decisions, next steps, claims to
  verify, the honest dissent and provenance. **The shape is fixed by
  `planning/docs/reference/reviews-are-advice.md`.** Session transcripts do not survive; these
  files are the durable record of what each review found.

## Cross-references
