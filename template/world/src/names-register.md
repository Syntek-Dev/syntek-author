The register is the one list of every name the book invents: people, places, peoples, creatures, objects and titles.
`spelling` treats every name here as a known word, and `continuity` checks the prose against it.
A name enters the register before it appears in promoted prose.

## How to add a name

- Add rows through `create-name`, or by hand keeping every column, one name per row, in alphabetical order.
- The Kind column takes one of `character · place · people · culture · creature · event · object · title · other`.
- The IPA column is broad IPA without slashes, and without a stress mark unless the name's language has a lexical stress rule, in which case ˈ marks the stressed syllable; the Respelling column is how an English-speaking reader should say the name, stressed syllable in capitals (VAH-ree).
- The Language column names the language the name comes from (a constructed language's slug, or English); the Meaning column gives its literal sense, or a dash when it has none.
- The First appears column takes `<unit-slug>/<section-slug>` for the first promoted section that uses the name, and stays empty until then.
- Never delete a row: a retired name keeps its row, with 'retired DD/MM/YYYY' in Notes, so a stray use in old prose is still caught.
