# CHECKLIST.md — create a creature

**Last Updated**: <%DATE%> **Version**: 0.1.0 **Maintained By**: <%AUTHOR_NAME%>
**Language**: British English (en_GB)

> **See** `world/docs/reference/creatures.md` and the `create-creature` skill. Gates cite
> `standards/verification/verification.md` by number; this list never restates them.

## Pre-Conditions

- [ ] Read `.claude/CLAUDE.md` and `.claude/MEMORY.md`, then this folder's `CONTEXT.md` and `CLAUDE.md`. · _sonnet_
- [ ] The creature's job in the story agreed with the author, with the scenes and plot moments that depend on it. · _opus_

## Execution Checklist

**Before inventing anything**

- [ ] Read the register, the existing bestiary, the creature's places and cultures, `planning/src/continuity.md` and any linked quest. · _opus_
- [ ] Established rules the creature must respect listed. · _opus_

**The creature**

- [ ] **Ecology settled before any ability: habitat, diet, predators, life cycle, numbers.** · _opus_
- [ ] Anatomy fits the ecology; behaviour recorded for hunger, threat, mating, injury and solitude. · _opus_
- [ ] Every ability written with its cost; every limit written as a hard rule. · _opus_
- [ ] Every weakness the plot uses checked for a set-up in `planning/src/causality.md`; missing set-ups noted. · _opus_
- [ ] Lore attributed to the people who hold it, with errors marked as errors. · _opus_
- [ ] Name options given per people, with IPA and respelling, clash-checked; the author chose each. · _opus_
- [ ] Draft compared with every established rule; contradictions reported with both locations. · _opus_

**Writing it down**

- [ ] Checked `world/src/creatures/<slug>.md` does not exist; if it did, stopped and asked. · _sonnet_
- [ ] Entry written from the skeleton, one sentence per line, `first_appears` empty. · _sonnet_
- [ ] One register row per name: kind `creature`, IPA, respelling, language, meaning. · _sonnet_

## Done When

- [ ] **The creature's limits are hard rules, and every weakness the plot uses has a set-up or is reported as lacking one.** · _opus_
- [ ] Nothing in the entry contradicts another world file without the author knowing. · _opus_
- [ ] Handed back: entry, names, missing set-ups, quest links to add, contradictions, open flags. · _opus_
