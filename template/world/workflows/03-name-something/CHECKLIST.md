# CHECKLIST.md — name something

**Last Updated**: <%DATE%> **Version**: 0.1.0 **Maintained By**: <%AUTHOR_NAME%>
**Language**: British English (en_GB)

> **See** `world/docs/reference/naming.md` and the `create-name` skill. Gates cite
> `standards/verification/verification.md` by number; this list never restates them.

## Pre-Conditions

- [ ] Read `.claude/CLAUDE.md` and `.claude/MEMORY.md`, then this folder's `CONTEXT.md` and `CLAUDE.md`. · _sonnet_
- [ ] Confirmed the thing needs only a name; otherwise routed to the character or place procedure. · _opus_

## Execution Checklist

**Before offering anything**

- [ ] Kind, origin, speaker, frequency, tone and register stated; for a renaming, the old name and the reason. · _opus_
- [ ] **Read `world/src/names-register.md` in full, and the naming customs of the name's culture.** · _opus_
- [ ] Where the name comes from a constructed language, its phonology, words and real-world models read; phonotactics followed. · _opus_

**Options and checks**

- [ ] Three to five options given, each with reasoning, IPA and a respelling, and each said aloud. · _opus_
- [ ] Every option checked for look-alike and sound-alike clashes against the register. · _opus_
- [ ] Every option checked for false friends (the model languages, English slang included), brands and prominent real people. · _opus_
- [ ] The author chose the name; a name of the author's own was checked the same way. · _opus_

**Recording**

- [ ] Register row added in alphabetical order, every column filled but First appears. · _sonnet_
- [ ] For a renaming: old row retired with the date, not deleted; sections using the old name listed. · _sonnet_
- [ ] Likely misspelling added to `standards/style/terminology.md`, where one exists and the author agreed. · _sonnet_

## Done When

- [ ] **The chosen name is registered before any promoted prose uses it.** · _opus_
- [ ] No clash was left unreported. · _opus_
- [ ] Handed back: the name, its IPA and respelling, accepted clashes, and any sections still using an old name. · _opus_
