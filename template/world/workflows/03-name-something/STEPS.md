# STEPS.md — name something

**Last Updated**: <%DATE%> **Version**: 0.1.0 **Maintained By**: <%AUTHOR_NAME%>
**Language**: British English (en_GB)

The ordered procedure for naming one thing and registering the name. Each step names the skill
and guide it uses. **Run in order** (options are checked before the author chooses, so the
choice is informed) and tick `CHECKLIST.md` as you go.

> Read the read-order files first (this folder's `CONTEXT.md` and `CLAUDE.md`). The
> `create-name` skill is this procedure in skill form.

## 1. State what is being named

> **Skill:** `create-name` · **Guide:** `world/docs/reference/naming.md`

The kind (character, place, people, culture, creature, event, object, title, other), the culture
or language it comes from, who says it and how often, the tone and register it should carry
(everyday, formal, sacred, intimate). If it is a renaming, the name being replaced and why.
_Substantive._

## 2. Read the register and the naming customs

> **Skill:** `create-name` · **Guide:** `world/docs/reference/naming.md`

Read `world/src/names-register.md` in full, and any naming customs recorded for the culture
the name comes from, in its world file or in `world/docs/project/`; with the worldbuilding kit,
read the people's file too. Where the constructed-language kit is installed and the name comes
from one of its languages, read that language's phonology, words and real-world models: the
options must obey its phonotactics, and may follow the models' naming habits. _Substantive._

## 3. Offer three to five options

> **Skill:** `create-name` · **Guide:** `world/docs/reference/naming.md`

Each option with its reasoning (sound palette, custom, meaning, the model's naming habit where
there is one), its IPA and a reader respelling with the stressed syllable in capitals. Vary
them: a safe choice, a bolder one, and one that breaks a custom deliberately, if breaking it
might serve the story. Say each aloud, at speed and in a sentence; drop any a reader would
stumble on. _Substantive._

## 4. Check every option for clashes and false friends

> **Skill:** `create-name` · **Guide:** `world/docs/reference/naming.md`

Against the register: look-alikes (shared initial, length and ending), sound-alikes (shared
stressed syllable or rhyme). Beyond it, false friends: an unintended meaning in the languages
the name is modelled on, in English (slang included) or another major language, a brand, a
prominent real person; checked, never assumed. Mark each option clean or name its clash.
_Substantive._

## 5. Let the author choose

> **Skill:** none (the author's decision) · **Guide:** `world/docs/reference/naming.md`

Present the options with their checks. Never choose on the author's behalf; if the author
offers a name of their own, check it the same way before registering it. _Substantive._

## 6. Register the name

> **Skill:** `create-name` · **Guide:** `world/docs/reference/naming.md`

Add one row to `world/src/names-register.md` in alphabetical order, filling every column but
First appears. For a renaming, mark the old row retired with the date in Notes and list the
sections that used the old name. _Mechanical._

## 7. Add a likely misspelling to the terminology list

> **Skill:** none · **Guide:** `world/docs/reference/naming.md`

Where the name has an obvious wrong form (a doubled letter, a familiar near-twin), and the
author agrees, add it as a form to avoid in `standards/style/terminology.md`. _Mechanical._

## 8. Hand back

> **Skill:** none · **Guide:** `world/docs/reference/naming.md`

Report the registered name with its IPA and respelling, any clash the author accepted, and, for
a renaming, the sections still using the old name. _Substantive._
